# REFERENCIAS: MÉTODOS NUMÉRICOS APLICADOS EN SOFTWARE

Para asegurar el rigor técnico y la actualidad de este curso, se han consultado las siguientes fuentes bibliográficas y documentaciones oficiales.

## 📚 Bibliografía de Referencia

1. **Chapra, S. C., & Canale, R. P. (2021). _Numerical Methods for Engineers_ (8th ed.). McGraw-Hill.**

   - _Uso_: Base teórica para los métodos de búsqueda de raíces, sistemas lineales y solución de ODEs (Runge-Kutta).
   - _Estatus_: Referencia estándar en ingeniería a nivel mundial.

2. **IEEE Computer Society. (2019). _IEEE Standard for Floating-Point Arithmetic (IEEE 754-2019)_.**

   - _Uso_: Sustento técnico para el Módulo 0 y la comprensión de errores de redondeo en software.
   - _Estatus_: Estándar vigente hasta 2029.

3. **Virtanen, P., et al. (2020). _SciPy 1.0: Fundamental Algorithms for Scientific Computing in Python_. Nature Methods.**
   - _Uso_: Validación de las implementaciones prácticas y algoritmos de optimización/integración en Python.
   - _Estatus_: Documentación técnica de la librería Scipy (actualizada a 2024).

## 🖥️ Documentación Técnica y Herramientas

- **SciPy v1.13+ Documentation (2024)**: [scipy.org](https://docs.scipy.org/doc/scipy/reference/)
  - Específicamente los subpaquetes `scipy.optimize` y `scipy.integrate`.
- **NumPy v2.0+ Documentation (2024)**: [numpy.org](https://numpy.org/doc/stable/)
  - Validación del estándar de manejo de arreglos y álgebra lineal computacional.
- **Python Standard Library - `math` module**: Sustento para funciones trigonométricas y logarítmicas de alta precisión.
