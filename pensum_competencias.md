# PENSUM DE COMPETENCIAS: MÉTODOS NUMÉRICOS APLICADOS EN SOFTWARE

## PERFIL DE EGRESO

Al finalizar este curso, el estudiante será capaz de:

1. Analizar problemas matemáticos y determinar si requieren una solución numérica.
2. Implementar algoritmos de cálculo de raíces, integración y solución de sistemas lineales en entornos de software modernos.
3. Evaluar críticamente los resultados de una simulación basándose en la comprensión de la propagación de errores.
4. Desarrollar software de simulación científica básica con un enfoque en la eficiencia y la precisión.

## MATRIZ DE COMPETENCIAS POR MÓDULO

| Módulo       | Competencia Específica (Saber Hacer)                | Resultado de Aprendizaje (Evidencia)                                    |
| :----------- | :-------------------------------------------------- | :---------------------------------------------------------------------- |
| **Módulo 0** | Gestionar la precisión numérica en código           | Calculadora de error relativo y absoluto implementada.                  |
| **Módulo 1** | Resolver ecuaciones no lineales mediante iteración  | Script que encuentra raíces de funciones complejas de forma automática. |
| **Módulo 2** | Resolver sistemas de ecuaciones de gran escala      | Motor de resolución de circuitos eléctricos o redes analógicas.         |
| **Módulo 3** | Modelar tendencias a partir de datos dispersos      | Algoritmo de regresión para predicción de crecimiento.                  |
| **Módulo 4** | Calcular áreas y derivadas sin funciones analíticas | Software de cálculo de integrales por aproximación.                     |
| **Módulo 5** | Predecir estados futuros de sistemas dinámicos      | Simulador de crecimiento poblacional o decaimiento radiactivo.          |
| **Módulo 6** | Integrar múltiples métodos en una solución única    | Simulador físico funcional con interfaz básica.                         |
