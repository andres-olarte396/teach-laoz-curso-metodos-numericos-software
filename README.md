# Curso de Métodos Numéricos

Este repositorio contiene el material del curso "Métodos Numéricos" desarrollado por Teach-Laoz.

## Objetivo

Proveer recursos educativos completos y estructurados para el aprendizaje de los métodos numéricos, enfocados en aplicaciones de ingeniería y ciencias.

## Público objetivo

Estudiantes universitarios, docentes y autodidactas interesados en métodos numéricos y su implementación práctica.

## Estructura

- **modulos/**: Contiene los módulos y temas del curso.
- **assets/**: Gráficos y simulaciones interactivas.
- **cronograma.md**: Cronograma del curso.
- **INDICE.md**: Índice general de contenidos.
- **REFERENCIAS.md**: Bibliografía y recursos.
- **REPORTE_VERIFICACION.md**: Reporte de verificación de competencias.
- **pensum_competencias.md**: Pensum y competencias del curso.
- **plan_curricular.md**: Plan curricular detallado.

### Descripción de carpetas y archivos principales

- **modulos/**: Cada subcarpeta corresponde a un módulo temático. Los archivos `.md` contienen teoría, ejercicios y evaluaciones.
- **assets/graphics/**: Imágenes y diagramas explicativos.
- **assets/simulaciones/**: Simuladores interactivos en HTML para experimentar con los métodos.
- **cronograma.md**: Planificación temporal del curso.
- **INDICE.md**: Navegación rápida por los contenidos.
- **REFERENCIAS.md**: Fuentes bibliográficas y enlaces recomendados.
- **REPORTE_VERIFICACION.md**: Evidencia del cumplimiento de competencias.
- **pensum_competencias.md**: Listado de competencias y resultados de aprendizaje.
- **plan_curricular.md**: Detalle de la estructura curricular.

## Uso

Este material está diseñado para facilitar el aprendizaje de los métodos numéricos aplicados a la ingeniería y ciencias.

### Ejemplo de uso

1. Explora el índice y el cronograma para planificar tu estudio.
2. Revisa los módulos en orden o según tu interés.
3. Utiliza los simuladores para experimentar con los conceptos.
4. Consulta las referencias para ampliar tu conocimiento.

### Requisitos

- Navegador web para visualizar simulaciones.
- Visualizador Markdown para leer los contenidos.
